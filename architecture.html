PUBLIC ARCHITECTURE NOTE · MINIMAL DISCLOSURE

知林 COLA Edition · 架构概览

公开仓库只展示代码框架、分层约束与工程能力，不包含账号、建库、AI、题库、计划、管理员等业务核心实现。

1. 设计目标

业务与框架解耦

领域层只表达业务规则；HTTP、存储、外部模型与旧系统放在适配层/基础设施层。

可替换适配器

同一套用例可以接 JSON 存储、关系库或旧服务；迁移时不需要改领域规则。

依赖倒置

领域定义端口（Protocol/ABC），基础设施实现端口；应用层只依赖抽象。

渐进式替换

新路由优先匹配，未迁移的路径落到旧服务，保证迁移期间产品持续可用。

2. 分层与依赖方向

Adapter

HTTP Controller、参数校验、响应包络、会话上下文。

Application

用例编排、事务边界、权限与幂等；只依赖领域端口。

Domain

实体、值对象、策略、领域错误；不依赖 HTTP/数据库/旧系统。

Infrastructure

Repository 实现、外部网关、旧系统防腐层、持久化。

Client

稳定的 DTO/契约，避免把内部模型直接暴露给前端。

Boot

组合根：装配实现、注册路由、启动服务。

Adapter→Application→Domain ←Infrastructure implements ports

硬规则：domain 不导入 adapter/application/infrastructure；application 不导入 adapter/infrastructure；基础设施可以依赖领域端口，但不能反向污染领域。

3. 请求链路

Browser→HTTP Adapter→Use Case →Domain Policy→Repository Port →JSON / Legacy Adapter

适配层负责把外部输入转换为用例参数；用例负责编排；领域策略负责规则判断；基础设施负责持久化或调用旧系统。错误通过稳定错误码返回，响应统一为 {code,message,data,traceId}。

6. 代码骨架（示意）

# domain/ports.py
class MasteryRepository(Protocol):
    def get_state(self, node_id: str) -> MasteryState: ...
    def save_state(self, node_id: str, state: MasteryState) -> None: ...

# application/use_cases.py
class SetProficiency:
    def __init__(self, repo: MasteryRepository): self.repo = repo
    def execute(self, node_id: str, value: int) -> MasteryState:
        state = self.repo.get_state(node_id)
        state.mastery = normalize_proficiency(value)
        self.repo.save_state(node_id, state)
        return state

# adapter/http/controller.py
@route("POST", "/api/v2/nodes/{nid}/proficiency")
def set_proficiency(ctx):
    state = service.set_proficiency(ctx["params"]["nid"], ctx["body"]["value"])
    return ok(state.to_dict())

7. 质量门禁

依赖方向测试

用 AST 扫描 import，发现领域层导入 HTTP/基础设施即失败。

领域单测

纯函数/策略测试，不启动服务、不连数据库。

用例测试

用内存 Fake Repository 验证编排、错误与边界。

兼容性冒烟

新路由优先匹配，旧路径回退；关键响应包络保持一致。

8. 渐进式迁移

阶段动作退出条件
P0建立分层、端口、组合根与依赖测试领域/应用层无外部依赖
P1迁移账号、额度、运行状态等低耦合切片v1 兼容路由通过冒烟
P2迁移熟练度读写与课程查询领域测试 + 页面回归通过
P3迁移建库、题库、计划、AI 网关端到端闭环通过
P4下线旧路由与旧模块回滚演练通过
