# ZhiLin UI Framework

知林的**只读 UI 框架**。本仓库只包含页面壳、基础导入解析和知识卡只读浏览，不是一个可复现的完整产品。

## 能做什么

- 导入完整产品导出的私有数据库 JSON
- 查看课程列表
- 查看知识树
- 查看知识卡片、来源和知识关系
- 查看索引表
- 切换浅色 / 深色主题

导入的数据只在浏览器本地解析，不上传服务器。支持 IndexedDB 的浏览器会在本地保留导入结果。

## 不包含什么

本仓库**不包含**：

- 登录、账号、会话或权限系统
- AI 模型、知乎直达或任何联网问答
- 资料解析、建库、知识树生成或增量更新
- 习题生成、作答、判题或复习
- 学习计划、今日安排或计时
- 知识导出、后台任务或任务中心实现
- 管理员后台、额度、配额或用户管理
- 后端服务、数据库、部署脚本或产品文档

所有页面中的相关入口只保留页面壳，并明确标记为未包含。本仓库不能用于复现完整产品。

## 本地运行

```bash
python -m http.server 8080
```

打开 `http://localhost:8080`。

点击「导入数据库」选择完整产品导出的 JSON 文件；也可以点击「加载示例数据」查看合成示例。示例数据只用于演示页面结构，不是真实课程。
